# 摩托车 D 照科一快刷 · 厦门 2026

独立的厦门摩托车 D 照科目一快速刷题页面，不覆盖仓库原有的系统分析师题库。

## 打开方式

在项目根目录执行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后访问：

- D 照科一快刷：<http://127.0.0.1:8000/kemu1.html>
- 原系统分析师题库：<http://127.0.0.1:8000/outputs/index.html>

## 功能

- 未做优先：未做题 → 错题 → 最久未复习的题；
- 答题后立即判题并显示解析；
- 判断题、单选题和图片题；
- 答对自动进入下一题，可随时跳过；
- 章节筛选、仅未做、仅错题、仅收藏；
- 键盘 `1-4` / `A-D` 选择，`Enter` 下一题，`←/→` 翻题，`F` 收藏，`X` 跳过；
- 学习进度、错题、收藏保存在浏览器 localStorage；
- 支持导入符合结构的 JSON 题库，并可恢复内置题库。

## 题库

题库不是交管部门或驾校一点通官方实时接口，不保证与考场题序或原文逐字一致。法规如有更新，以厦门交警最新公告为准。
