跨端同步（GitHub Gist）

把学习记录同步到你 GitHub 账号下的一个 secret Gist，手机和电脑就能互通。 不需要服务器，也不额外花钱，数据只存在你自己的账号里。
获取 Token：GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → 只勾 gist → 生成后粘贴到这里。
Token 仅存在本机浏览器、不会上传；DeepSeek 的 API Key 不参与同步。
